# 产品规格（Product Spec）

## 1. 一句话定位

一个现代化、开源、本地优先的 Windows 桌面中国象棋复盘与 AI 分析软件，以本地 Pikafish 引擎为算力核心。

## 2. 目标用户

- 业余与进阶象棋爱好者：赛后复盘、拆解变例、理解关键招。
- 教练/棋谱整理者：整理与导出带注释、多变例的棋谱。
- 开发者/极客：偏好本地运行、可审计的开源工具，不依赖云服务。

## 3. 目标（Goals）

- 完整可交互的中国象棋棋盘与合法走棋。
- 以「棋谱树」组织主线 + 多变例 + 注释的复盘体验。
- 本地 Pikafish 引擎：局面分析、MultiPV、自动复盘、评价曲线。
- 棋谱多格式导入导出（FEN/PGN/XQF/TXT/东萍），与主流打谱软件互通。
- 本地开局库 + 云库（可降级）+ 自动走库。
- 截图识别局面（可手动校正）。
- 现代桌面体验：深浅色模式、快捷键、GIF 导出。
- Windows 安装版 + 便携版，GitHub Actions 自动构建与 Release。

## 4. 非目标（Non-goals / 反目标）

- 不做在线对弈/联机平台（本地分析与复盘工具，不含对战匹配）。
- 不做引擎对弈的复杂时间制/联赛管理（只保留「皮卡鱼执红/黑走棋」这类基础功能；Skill Level/UCI_Elo 通过引擎参数暴露即可）。
- 不追求移动端/跨平台优先（首版仅 Windows；架构上不排斥未来复用，但不为此预建抽象）。
- 不内置云存储同步、账号体系、社区分享。
- 不自行训练 NNUE 权重，不自行维护云库。

**额外能力（超出网页版基线，属于桌面本地优先的差异化）：**

- 本地开局库（离线可用，不依赖云库）。
- 自动复盘（整局批量分析，生成评价曲线与逐着点评）。
- 评价曲线可视化（局面评分随时间/回合的变化图）。
- 深浅色主题切换。
- 全局快捷键。
- Windows 安装版 + 便携版，GitHub Actions 自动化发布。

## 6. 产品架构（Product Architecture）

产品按「面向用户的能力域」划分为 7 个模块，模块间通过明确边界交互：

```
┌────────────────────────────────────────────────────────────┐
│                        UI 层（React）                        │
│  棋盘 | 棋谱树 | 走法列表 | 评价栏 | 引擎面板 | 注释编辑 | 对话框 │
└──────────────────────────┬─────────────────────────────────┘
                           │ Tauri IPC（invoke）
┌──────────────────────────▼─────────────────────────────────┐
│                    Rust Core（领域核心）                       │
│  棋盘规则 | 棋谱树 | FEN | 导入导出 | 开局库 | OCR | 数据库      │
└──────┬───────────────────────────────┬──────────────────────┘
       │                               │
┌──────▼──────────────┐        ┌───────▼──────────────┐
│   Engine Manager     │        │   Book Provider       │
│   （进程/UCI 管理）    │        │   本地库 / 云库        │
└──────┬──────────────┘        └───────────────────────┘
       │
┌──────▼──────────────┐
│   Pikafish（外部进程） │
│   UCI 引擎 + NNUE     │
└─────────────────────┘
```

**能力域划分：**

1. **棋盘与规则域**：棋盘渲染所需数据、走法生成、合法性校验、FEN、胜负/和棋判定。始终离线可用。
2. **棋谱域**：棋谱树（主线/变例/注释/NAG）、导航、编辑操作。
3. **引擎域**：引擎进程生命周期、UCI 通信、MultiPV、参数、分析与评价曲线。
4. **导入导出域**：FEN/PGN/XQF/TXT/东萍 的解析与序列化。
5. **开局库域**：本地库、云库、自动走库。
6. **识别域**：截图识别局面（可降级）。
7. **呈现域**：主题、快捷键、GIF 导出、布局。

## 7. 非功能需求（NFR）

| 维度 | 要求 |
|------|------|
| 稳定性 | 引擎崩溃/无响应不拖垮主进程；UI 始终可操作，分析可随时停止 |
| 离线 | 棋盘、走法、复盘、本地开局库、导入导出完全离线可用 |
| 性能 | 引擎分析在后台线程，不阻塞 UI；棋盘渲染 60fps 流畅 |
| 可测试 | 规则与棋谱树逻辑为纯函数/Rust 单元可测；UCI 解析可离线回放 |
| 可维护 | 单一事实来源；模块边界清晰；文档与代码同库 |
| 可扩展 | 新增棋谱格式/开局库来源只需实现一个 trait，不触碰核心 |
